The network

Residential IPs that behave like real people, because they are.

Every exit is a genuine household connection on a real consumer ISP. No datacentre ranges, no recycled subnets, no fingerprints that give the game away at the first challenge.

Targeting by country and city

Address your request by country, region or city, all expressed in the username. No separate endpoint, no separate port, no configuration change.

Sticky or rotating

Hold the same residential exit for up to an hour, or rotate on every single request. You decide per session, with no configuration change.

No thread caps

No device limits and no per-port allocation. Open as many parallel sessions as your own infrastructure can carry.

HTTP, HTTPS & SOCKS5

One gateway, three protocols. Drop-in compatible with Playwright, Puppeteer, Selenium, requests, Go and plain curl.

Automatic retry

If a peer drops mid-request, the gateway retries across the pool at no extra cost rather than handing you the failure.

Usage you can check

Ask the bot for your balance and traffic at any time. Prepaid, billed per gigabyte, and it never expires.

Targeting

Real addresses, in the places that matter.

Pools are first-party. Addresses rotate continuously, and any exit can be retired from the pool on request.

Every address is checked for reachability before it enters rotation and re-checked while it is in use. Peers that stop answering are pulled automatically.

  • Country targetingAny country in the pool
  • City targetingWhere available
  • Session controlSticky or per-request
  • ProtocolsHTTP, HTTPS, SOCKS5
  • AuthenticationUsername based
  • Peer failureAutomatic retry

Coverage grows as the network does. Ask the bot for the current country list before you commit.

Developers

One endpoint. Any language.

Authenticate once with the credentials you're issued, then route everything through your endpoint. Your endpoint and credentials are handed over when your account is provisioned — they aren't published here.

  • Rotating and sticky sessions on the same port
  • IPv4 residential exits
  • Traffic caps on the account, visible in the bot
  • SOCKS5 for UDP and non-HTTP workloads
  • Works with any HTTP client, no SDK required
# rotate the exit IP on every request
curl -x http://USER:PASS@YOUR-ENDPOINT:8000 \
     https://api.ipify.org

# pin one exit for ten minutes
curl -x http://USER-country-us-session-a41f:PASS@YOUR-ENDPOINT:8000 \
     https://api.ipify.org
import requests

proxy = "http://USER-country-de-session-a41f:PASS@YOUR-ENDPOINT:8000"

r = requests.get(
    "https://api.ipify.org?format=json",
    proxies={"http": proxy, "https": proxy},
    timeout=20,
)

print(r.json())
import { ProxyAgent } from 'undici';

const proxy = 'http://USER-country-jp-session-a41f:PASS@YOUR-ENDPOINT:8000';

const res = await fetch('https://api.ipify.org?format=json', {
  dispatcher: new ProxyAgent(proxy),
});

console.log(await res.json());

Questions

The things people ask first.

Still unsure? Message the bot — you will get a person, usually within the hour.

What exactly is a residential proxy?

A residential proxy routes your request through a genuine household connection, so the destination site sees a real consumer IP on a real ISP — not a datacentre range, and not a subnet that has been flagged a thousand times before.

How do I get access?

Message the bot and tell it roughly what you are running and how many gigabytes a month you expect. You will be sent payment details, and once you have paid you get a single-use code to redeem for a live account. Your endpoint and credentials come with it.

Which protocols do you support?

HTTP, HTTPS and SOCKS5 on the same endpoint and the same credentials. WebSocket upgrades work over HTTP without extra configuration.

How does billing work?

Prepaid bandwidth, billed per gigabyte as you use it. The minimum purchase is $20, the balance never expires, and there is no minimum term — you top up again whenever you run low.

Can I check my usage?

Yes. Ask the bot for your balance at any time and it will tell you what you have used against your cap. You are also notified automatically when you are running low.

Can I reserve a dedicated pool?

Yes, at $29 a month. You get a pool reserved for your account alone, so your throughput never competes with another tenant. Ask the bot and it will size it with you.
